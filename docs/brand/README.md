# 昨日头条 Logo

`daily-history-source.png` 是用户于 2026-11-21 提供的 `1.png` 原文件副本。
素材是红色报纸造型，包含 `DAILY HISTORY` 和 `28`，图案与文字沿用原稿。

运行 `python scripts/prepare-brand-icons.py` 可重新生成 Android 各密度图标、
自适应前景、开屏标志、网页 favicon 和 Apple touch icon。
该步骤只处理已有透明边界、比例、留白和文件格式，不重绘 Logo。

Android 图标前景为 108dp 画布，图案放在居中的安全圆内，背景为白色。
圆形与圆角桌面图标使用同一组素材。系统开屏与应用开屏均引用相同标志。
