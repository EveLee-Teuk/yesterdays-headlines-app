# 开屏与 Android 安装包

目标：保留线上每日更新，增加同风格开屏，交付可直接安装的签名 APK。

采用轻量联网版。网页每个标签页会话只显示一次可跳过的开屏；原生应用显示本地开屏并跳过网页开屏。断网给出重试入口，不承诺离线日报。暖白背景、毛笔标题和朱红小印沿用当前设计。

实现顺序：
1. 新增 LaunchScreen 客户端组件及响应式样式，尊重减少动画设置，不挡住无 JS 阅读。
2. 新建 android 工程：受限站点 WebView、系统返回、网络失败重试、外部出处链接交给浏览器、保存 PNG 使用系统文件选择器。
3. 通过受限来源 WebMessageListener 传递 PNG，不开放通用 JavaScript 接口。
4. GitHub Actions 使用 Java 17 / Gradle 8.9 / AGP 8.7.3 构建。签名密钥只存本地私有文件与 GitHub 加密 Secret，不纳入源码和构建产物。
5. 检查网页类型、测试和生产构建；Android lint、签名验证及模拟器启动检查；下载 APK 并验证哈希，部署网页。

最低 Android 8.0。APK 加载固定 HTTPS 生产域名，不含 DeepSeek 密钥。浏览记录及收藏存于本机 WebView，与浏览器收藏互不共享。后续网站内容更新无需重装；原生能力修改需要新 APK，保留同一签名与包名以支持覆盖安装。
